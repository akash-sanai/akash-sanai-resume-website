# Akash Sanai – Resume Website

## Files
- `index.html` – semantic HTML structure and resume content
- `styles.css` – responsive styling, colour palette, typography and layouts

## Run locally
Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.

## Publish with GitHub Pages
1. Add `index.html` and `styles.css` to the root of the same GitHub repository used for the HTML resume assignment.
2. Commit and push the files.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. After deployment, copy the published URL shown in GitHub Pages.

## Design implementation
- Element selectors: `body`, `h1`, `h2`, `h3`, `a`
- Class selectors: `.navbar`, `.hero`, `.experience-card`, `.skill-card`
- ID selectors: `#about`, `#experience`, `#education`, `#skills`, `#contact`
- Flexbox: navigation, action buttons, contact and footer alignment
- CSS Grid: hero, experience, education and skills layouts
- Positioning: sticky navigation header
- Responsive design: media queries for tablet and mobile widths
